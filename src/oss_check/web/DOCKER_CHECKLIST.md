## R5 강의 요소 적용 근거 (2026-11-27)

설계지침 §7의 L08·L19·L20을 현재 구현과 대조했다. 위 Docker 점검 기록과 별개로, 이번에는 주석과 이 근거만 정리했다.

| ID | 적용 위치 | 어떻게 사용했는지 | 확인 상태 |
|---|---|---|---|
| L08 함수 어노테이션 | `web/routers/pages.py`의 `home`, `report_response`; `web/forms.py`의 `read_form` | 요청은 `Request`, 폼 해석 결과는 `FormData`, 화면 응답은 `HTMLResponse`로 표시했다. 결과 표시 함수는 공통 `Report`를 받도록 적어 연결 형식을 드러냈다. | 기존 타입 표기와 강의 주석 확인. L16 mypy 통과를 뜻하지는 않음. |
| L19 가짜 객체 | `tests/web_fakes.py`의 `WebPackageSource`, `install_web_source`; `tests/test_FR_IN_01_web_analysis.py` | 실제 조회 객체 대신 준비한 메타데이터를 반환하는 객체를 넣는다. R0·R1·R2·R3 분석 코드는 그대로 호출해, 외부 통신 없이 업로드·분석·결과 표시를 확인한다. | 가짜 조회 객체에 강의 주석 추가. 웹 회귀 검사 20개 통과. |
| L20 Docker | 루트 `Dockerfile`의 `FROM`, `COPY`, `RUN`, `CMD` | Python 기본 환경에 코드와 라이브러리를 넣고 Uvicorn으로 앱을 실행한다. 팀원별 실행 환경 차이를 줄인다. | 기존 빌드·실제 분석 점검은 위 기록 참조. 이번에는 강의 주석을 보완했으며 이미지를 다시 빌드하지 않음. |
