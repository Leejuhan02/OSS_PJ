- R2 PR #37: rfc3987 식별·최상단 판정, jsonpointer 식별 문제 해결 확인. 별칭 확장 반영.
- R4 PR #38: 캐시 분리 반영. 이전 실패 순서(user-agent 검사 → 200 응답 검사)도 **2 passed**.

- 실제 PyPI 조회는 Docker 수동 점검에서 수행. pytest에서는 외부 API를 호출하지 않음.
- 11월 4일 확인한 크기 제한·인코딩·입력 복구·이스케이프·로그 보호 결과는 이전 기록이며, 이번 브라우저 점검에서 모두 반복한 것은 아님.
